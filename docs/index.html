Codex in your desktop browser.

Work with Codex projects and conversations through a web interface. Run the server on Linux, macOS, or Windows, then connect locally or through your authenticated remote setup.

This fork maintains desktop web access. Telegram integration, mobile layouts, PWA installation, and Android/Termux runtimes have been removed.

Projects, conversations, and tools

  • Chat with streaming replies, reasoning, and multiple conversations.
  • Organize projects and inspect code changes in the desktop sidebar and review panels.
  • Use the terminal, Skills Hub, and plugin directory from the browser.
  • Import and export projects with their conversation history.
  • Connect through local, LAN, reverse proxy, or tunnel access.

Desktop interface

Build this fork

Install Node.js 18 or later, pnpm, and the Codex CLI, then build the desktop web server:

git clone https://github.com/ArcturusL/codex-mobile.git
cd codex-mobile
pnpm install
pnpm run build
node dist-cli/index.js --no-tunnel --no-open

Open the URL printed by the server in your desktop browser. Authentication is enabled by default; startup output identifies the password file. See the repository README for remote access options.

How it runs

The Vue interface connects to the Node.js web server over HTTP and WebSocket. The server bridges requests to the Codex app-server process.

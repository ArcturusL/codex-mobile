### Feature: Desktop-only project website

#### Prerequisites
- Serve this checkout's `docs/` directory locally or open `docs/index.html` in a browser.

#### Steps
1. Open the website in light and dark themes at a desktop viewport (1440x900).
2. Follow the Features, Screenshots, and Build navigation links.
3. Confirm both desktop screenshots load and the build instructions reference this fork.
4. Confirm there are no Telegram setup, Google Play, APK download, phone screenshot, or external embedded demo entries.

#### Expected Results
- The website describes desktop browser support on Linux, macOS, and Windows.
- Build instructions launch the authenticated desktop web server.
- Both themes remain legible and navigation reaches the correct sections.

#### Rollback/Cleanup
- Stop the local static server if one was started.
